# OUTSMART THE SQUAD — Ghidul de Supraviețuire Financiară
### Proiect realizat de Echipa Bright Minds • Craiova

Acest repository conține întregul cod sursă al aplicației web și al simulatorului interactiv creat pentru Competiția Națională de Educație Financiară pentru Tineri.

---

## 🚀 Cum rulezi proiectul local:
Deschide direct fișierul `index.html` în orice browser modern (Chrome, Edge, Firefox, Safari) cu dublu-click. Nu necesită instalare de pachete sau server Node.js.

---

## ⚡ Cum îl pui pe Vercel în 60 de secunde (Deploy Gratuit):

### Varianta A: Cu GitHub (Recomandat)
1. Fă un repository nou pe contul tău de [GitHub](https://github.com) (ex: `outsmart-the-squad`).
2. Urcă fișierul `index.html` și acest `README.md` în repo.
3. Intră pe [Vercel.com](https://vercel.com) și apasă pe **„Add New...” ➔ „Project”**.
4. Selectează repository-ul de pe GitHub și apasă **„Deploy”**.
5. În 10 secunde ai un link live securizat (HTTPS) pe care îl poți trimite juriului sau pune în formularul de concurs!

### Varianta B: Fără Git (Direct Drag & Drop)
1. Intră pe [app.netlify.com/drop](https://app.netlify.com/drop) sau [Vercel CLI](https://vercel.com).
2. Trage direct folderul cu `index.html` în fereastra de browser.
3. Link-ul se generează instantaneu!

## 🛠 Tehnologii folosite:
* **HTML5 Semantic & Dark Mode Design**
* **Tailwind CSS (CDN)** — Styling modern fintech / glassmorphism
* **Lucide Icons** — Iconițe vectoriale clare
* **Canvas Confetti** — Animații interactive de victorie
* **Vanilla JavaScript** — Motorul decizional al simulatorului (scenarii, bugete, reputație și FOMO)
